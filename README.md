# 🩸 2011X Discord Bot

Bot de Discord con Inteligencia Artificial inspirado en **2011X (Outcome Memories / Roblox)**, equipado con persistencia en **Firebase Realtime Database** y motor de memoria asíncrono.

## 🚀 Características
- **Personalidad 2011X**: Sádico, condescendiente, con complejo de deidad, enfocado en "juegos" y con modo *Rage* cuando se le provoca.
- **Memoria en Tiempo Real**: Almacena historiales de chat y hechos de usuario en Firebase Realtime Database.
- **Motor de Memoria con IA Dedicada**: Extracción asíncrona de hechos y síntesis contextual en segundo plano.
- **Servidor Web Express Integrado**: Inicio inmediato en `$PORT` listo para Render Free Web Service.
- **Slash Commands**: `/ping`, `/memoria`, `/olvidar`, `/estado`.
